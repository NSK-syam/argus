# Python 3.10 variant of backend/requirements.txt for the Hugging Face
# Space ONLY. Free Gradio Spaces run on the ZeroGPU image, which is pinned
# to Python 3.10 and ignores python_version; four of the backend's pins
# require >=3.11, so they're lowered here to the newest release that still
# supports 3.10. Because scikit-learn differs from the version the
# committed demo bundle was pickled with, deploy/huggingface/hf_space.py
# rebuilds the bundle at startup on this platform (see BUNDLE_SKLEARN).
# Everything else is identical to backend/requirements.txt.
# --- implemented and exercised by the current code (backend/app/ml, tests) ---
# pandas/numpy/scikit-learn/xgboost are pinned EXACTLY (not >=) because
# backend/app/demo_bundle/ ships real pickled model artifacts -- a clean-
# machine verification pass found that an unpinned `scikit-learn>=1.4`
# resolves to whatever is newest on the day someone installs it, which
# raised InconsistentVersionWarning against the committed demo bundle
# (built with 1.8.0) the moment pip picked up 1.9.1. Pinning keeps a
# fresh `pip install` reproducing the exact environment the bundle and
# every documented benchmark number (test RMSE 18.42, etc.) were
# generated with.
pandas==2.3.3
numpy==2.2.6
scikit-learn==1.7.2
xgboost==3.2.0
